**[GitHub Copilot app][about-copilot-app]** は、エージェントを活用した開発のためのデスクトップアプリケーションです。GitHub Copilot CLI を基盤とし、GitHub とネイティブに統合されているため、リポジトリ、ブランチ、CI パイプラインをすぐに利用できます。自分ですべての作業を行うのではなく、それぞれ独立したワークスペースで複数のエージェントに並列で指示を出し、繰り返し作業を自動化するワークフロー向けに設計されています。Node.js のインストールとプロジェクトの準備ができたので、次はアプリをインストールしてリポジトリを接続します。

このレッスンでは、次の操作を行います。

- GitHub Copilot app をインストールしてサインインします。
- GitHub リポジトリからプロジェクトをアプリに追加します。
- テンプレートによって用意されたバックログを含め、ワークスペースの使い方を確認します。
- クイックチャットを試して、アプリについて質問します。

## シナリオ

チームは、増え続けるバックログに取り組むために AI エージェントを導入しています。Copilot app を使うと、Issue の選択、エージェントの実行、変更のレビュー、pull request のマージを一か所から指示できます。このレッスンでは、アプリをインストールして接続し、プロジェクトについての会話を始める準備をします。

> [!NOTE]
> 対象となる Copilot プランが必要です。Copilot Free、Copilot Student、またはいずれかの有料プラン (Pro、Pro+、Business、Enterprise) を利用してください。Copilot Business または Copilot Enterprise を使用している場合、管理者が **GitHub Copilot app** ポリシーを有効にしている必要があります。

## GitHub Copilot app をインストールして構成する

GitHub Copilot app を使用するには、まずアプリをインストールします。Windows、macOS、Linux 向けのバージョンが用意されています。アプリをインストールして認証し、Tailspin Toys リポジトリを追加しましょう。

1. ブラウザーで [GitHub Copilot app のランディングページ][download-app]を開きます。
2. 使用しているプラットフォーム向けのアプリをダウンロードし、ランディングページの手順に従ってインストールします。
3. インストール後、アプリを開きます。
4. **Sign in to GitHub** を選択し、画面の指示に従って認証します。データレジデンシー付き GitHub Enterprise Cloud を使用している場合は、**Use GitHub Enterprise** を選択し、求められたら `*.ghe.com` のホスト名を入力します。GitHub Enterprise Server はサポートされていません。
5. オンボーディングでリポジトリの選択画面が表示されたら、テンプレートから作成した Tailspin Toys リポジトリを選択します。リポジトリの選択をスキップし、オンボーディング後にプロジェクトを追加することもできます。
6. テーマの選択を求められたら選択し、オンボーディングを完了します。
7. サイドバーの **Sessions** の下にリポジトリが表示されているか確認します。すでに表示されている場合は、もう一度追加する必要はありません。
8. リポジトリがまだ接続されていない場合は、**Sessions** の横にある **+** を選択して新しいセッションを作成し、**Add GitHub repository** を選択します。前提条件のレッスンで記録した Owner とリポジトリ名を指定します。
9. リポジトリがサイドバーに表示されていることを確認します。このレッスンで使用するレイアウトでは、`tailspin-toys` などのリポジトリフォルダーが **Sessions** の下にグループ化され、その下に個々のセッションが表示されます。

## ワークスペースの使い方を確認する

プロジェクトを接続したら、アプリの使い方を確認しましょう。サイドバーには次の領域があります。

- **New** - ここから Copilot との新しいチャットセッションを開始できます。
- **Pull requests** - アプリの GitHub ネイティブ統合を通じて pull request が表示されます。アプリを離れずに、pull request の参照や絞り込み、CI ステータスの確認、レビューを行えます。
- **Issues** - 同じように Issue が表示されます。Issue の参照や絞り込み、Issue からのセッション開始を行えます。
- **Automations** - スケジュールまたはオンデマンドで実行する、保存済みのエージェントタスクです。ToDo リストの管理、定期的なプロジェクトの保守、その他の面倒な作業を任せるのに役立ちます。まとめでは次のステップとして紹介しますが、ワークショップの演習には含まれません。
- **Customize** - MCP サーバー、プラグイン、スキルなどのコンポーネントを追加して、Copilot app の機能を拡張します。Playwright MCP の設定に使用します。
- **Chats** - 独自のブランチやワークスペースを必要としない、質問やブレインストーミングのための簡易的な会話です。最初のチャットを開始すると、このセクションが表示されます。表示されていない場合は、**Sessions** の横にある **+** を選択して最初のチャットを開始してください。
- **Sessions** - リポジトリフォルダーと、その中のエージェントセッションがグループ化されます。`tailspin-toys` などのリポジトリ名を選択するとリポジトリビューが開き、その下のセッションを選択すると会話に戻れます。各セッションは独立したワークスペースで実行されるため、変更を干渉させずに複数のセッションを同時に実行できます。最初のセッションは、星評価を追加するレッスンで開始します。

ワークショップを進めながら、ワークスペースの各機能を確認していきます。

> [!TIP]
> 迷ったときは Copilot に質問しましょう。操作方法がわからない場合や、何かが可能かどうか知りたい場合は、Copilot に尋ねると案内してくれます。

### 用意されたバックログを確認する

バックログのないプロジェクトはほとんどなく、Tailspin Toys も例外ではありません。テンプレートからリポジトリを作成したときに用意されたバックログを確認しましょう。

1. サイドバーの **Sessions** で、個別のセッションではなく Tailspin Toys のリポジトリフォルダーを選択します。次に、リポジトリの上部ナビゲーションで **Issues** を選択します。
2. Issue 番号を決めつけず、次のタイトルで探します。

   - Allow users to filter games by category and publisher
   - Update our repository coding standards

3. Issue を選択して詳細を読みます。各 Issue はエージェントセッションの開始点にもなります。小規模な最初の変更を終えた後、フィルター機能の Issue から作業を開始します。

> [!NOTE]
> **Issues** と **Pull requests** の一覧は自動的に絞り込まれ、Copilot app に追加したリポジトリの項目だけが表示されます。ほかのリポジトリの作業項目を表示するには、そのリポジトリをアプリに追加してください。

## クイックチャットを試す

アプリに慣れるには、アプリ自体について質問するのが効果的です。その用途には**クイックチャット**が適しています。クイックチャットでは、ブランチや worktree を作成せずに質問やブレインストーミングができます。セッションを必要としない、その場限りの簡単な質問に最適です。

1. サイドバーの **Chats** の横にある **+** を選択し、新しいチャットを開きます。**Chats** がまだ表示されていない場合は、**Sessions** の横にある **+** を選択して最初のチャットを開始してください。その後、**Chats** が表示されます。
2. アプリのセッションがどのように動作するかを尋ねます。

   ```plaintext
   How does the GitHub Copilot app use worktrees?
   ```

3. 会話ビューで回答を読みます。各セッションが独立した git worktree で実行されるため、変更を干渉させずに複数のエージェントを並列で実行できることがわかります。会話はいつでも続けられ、新しいチャットも開始できます。

## まとめと次のステップ

GitHub Copilot app をインストールし、プロジェクトを接続して、ワークスペースの使い方を確認しました。次の操作を行いました。

- アプリをインストールして GitHub にサインインしました。
- GitHub リポジトリからプロジェクトをアプリに追加しました。
- ワークスペースの使い方を確認し、**Issues** で用意されたバックログを見つけました。
- クイックチャットで、その場限りの簡単な質問をしました。

次は[最初のエージェントセッションを開始し][next-lesson]、ゲームカードに星評価を表示する変更を加えます。
