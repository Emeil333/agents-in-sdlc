Explore o GitHub Copilot ao longo do ciclo de vida do desenvolvimento de software com cenários realistas, um aplicativo completo e uma lista de pendências compartilhada. Você trabalhará de forma iterativa para planejar alterações, criar código, testar o comportamento, revisar pull requests e gerenciar o trabalho com agentes.

## Cenário

Você é uma nova pessoa desenvolvedora na Tailspin Toys, uma empresa fictícia que oferece financiamento coletivo para jogos de tabuleiro com um tema voltado a desenvolvedores. A lista de pendências da equipe já foi criada como issues do GitHub e está pronta para você escolher uma tarefa. Ela inclui recursos, como filtragem e paginação, e melhorias de qualidade, como acessibilidade e padrões de programação.

## Escolha seu ambiente

O GitHub Copilot acompanha você no ambiente em que trabalha. Escolha aquele que combina com a maneira como quer desenvolver. Cada workshop começa com sua própria configuração e usa o cenário compartilhado da Tailspin Toys.

### [GitHub Copilot CLI][cli]

Use o assistente com agentes no terminal. Trabalhe com os modos Plan e Autopilot, instruções, skills, agentes personalizados, Playwright MCP, Agent Merge e comandos de barra úteis.

### [Aplicativo GitHub Copilot][app]

Execute sessões de agentes em paralelo, alterne os modos de sessão, colabore em canvases e gerencie issues e pull requests do GitHub no aplicativo para desktop.

### [Agente de nuvem do GitHub Copilot][cloud]

Atribua issues do GitHub a um agente assíncrono, oriente o trabalho, acompanhe o progresso e revise os pull requests que ele abrir.

### [Visual Studio Code][vscode]

Use o GitHub Copilot no Visual Studio Code e no GitHub Codespaces. Trabalhe com o modo de agente do Copilot Chat, servidores MCP e agentes personalizados sem sair do editor.
